# 🦉 EduPlan AI

Bem-vindo ao **EduPlan AI**! Um assistente de mesa projetado especialmente para professores, focado em agilizar e otimizar a criação de planejamentos de aula com o poder da Inteligência Artificial e alinhamento total à BNCC (Base Nacional Comum Curricular).

## 📌 O que é o EduPlan AI?
O EduPlan AI é um aplicativo multiplataforma (funciona em Windows, macOS e Linux) que ajuda educadores a estruturarem suas aulas de forma rápida. Em vez de gastar horas formatando documentos e buscando códigos da BNCC, o professor preenche os dados básicos da aula e a Inteligência Artificial gera um planejamento completo.

## 🚀 Principais Funcionalidades
- **Geração Inteligente:** Criação de planos de aula estruturados via IA.
- **Integração com a BNCC:** Base de dados atualizada embutida no aplicativo.
- **Pronto para uso:** Não requer instalação complexa. É só baixar e usar.
- **Exportação Fácil:** Salve seus planos em formatos prontos para impressão ou edição.

## 📥 Como baixar e instalar

Você não precisa entender de programação para usar! Basta acessar a nossa área de downloads oficiais:

👉 **[CLIQUE AQUI PARA BAIXAR A VERSÃO MAIS RECENTE](../../releases/latest)** 👈

Escolha o arquivo correto para o seu computador:

### 🪟 Para Windows
1. Baixe o arquivo **`EduPlanAI-Windows.exe`**.
2. Dê um duplo clique no arquivo baixado. *(Se o Windows SmartScreen exibir um aviso de segurança por ser um app novo, clique em "Mais informações" e depois em "Executar assim mesmo").*

### 🍎 Para macOS
1. Baixe o arquivo **`EduPlanAI-macOS.zip`**.
2. Extraia o arquivo ZIP.
3. Dê um duplo clique no aplicativo **EduPlanAI** para abri-lo. *(Se o Mac bloquear a abertura, vá em Ajustes do Sistema > Privacidade e Segurança e clique em "Abrir Mesmo Assim").*

### 🐧 Para Linux
1. Baixe o arquivo **`EduPlanAI-Linux`**.
2. Clique com o botão direito no arquivo, vá em **Propriedades > Permissões** e marque a caixa para permitir a execução como um programa.
3. Dê um duplo clique para abrir.
